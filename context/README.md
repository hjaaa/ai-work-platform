# Context 知识层

本目录是 AI Agent 的长期记忆系统，采用"位置即语义、文档即记忆"设计。
人和 AI 读同一份文件，高频使用天然对抗文档腐化。

## 目录结构

```
context/
├── team/        # 团队级：所有项目通用的规范和流程
├── project/     # 项目级：特定项目/服务的知识
├── experience/  # 经验级：踩坑沉淀、常见错误、自检清单
└── rules/       # 规则级：Agent 自动化约束（上下文映射、风险识别）
```

## 使用原则

1. **JIT 加载**：Agent 不应预加载所有文件，而是先读 `experience/index.md` 索引，按需加载
2. **2 分钟沉淀**：AI 犯错时花 2 分钟记一句话，比花 30 分钟写完美文档更有价值
3. **不追求完美格式**：记了就行，格式可以后续迭代
4. **位置即语义**：文件放在哪个目录，AI 就知道它是什么
5. **高频消费对抗腐化**：文档过时 → AI 行为出错 → 立刻发现并修正
