## 代码实施完成后自检清单

- [ ] **TDD 强制**：是否先写了测试再写实现？新增/修改的 Service 方法必须先有测试（红灯→绿灯），不允许"先实现后补测试"
- [ ] ProcessBuilder/外部进程调用逻辑是否有重复？是否应该复用 `ProcessExecutor` 工具类？
- [ ] Controller 是否直接注入了 Mapper？必须通过 Service 层访问数据
- [ ] 是否有定义了但未使用的类/方法（死代码）？实施结束后全局搜索确认
- [ ] 文件树/递归遍历类操作是否有深度和节点数限制？防止大项目阻塞
- [ ] 同一请求中是否有重复的 DB 查询？查询结果应传参复用
- [ ] 新增/修改的业务逻辑是否有对应的单元测试？（正常 + 边界 + 异常）
- [ ] Service 拆接口后，旧测试是否同步修改为引用 Impl 类？
- [ ] `@Async` 方法是否在独立 bean 中？同 bean 内调用不走代理
