# 开发流程强制规则

> Agent 在开发过程中必须遵守以下规则，违反时应自动修正。

## 规则表

| ID | 规则名 | 触发条件 | 强制行为 |
|----|--------|----------|----------|
| D001 | 数据库变更必须同步 Flyway 脚本 | 新增/修改功能涉及表结构变更（新增表、加字段、改字段、加索引等） | 必须在 `platform-web/src/main/resources/db/migration/` 下新增 `V{N}__描述.sql` 脚本，版本号递增，禁止修改已有脚本 |

## 规则说明

### D001 数据库变更必须同步 Flyway 脚本

**为什么：** Agent 容易只改 Java 代码（Entity、Mapper）而遗忘数据库迁移脚本，导致应用启动时表结构与代码不匹配。

**检查点：**
1. 新增或修改了 Entity 类 → 检查是否需要新建迁移脚本
2. Mapper XML 中出现了新表名或新字段 → 必须有对应的迁移脚本
3. 迁移脚本使用 `CREATE TABLE IF NOT EXISTS` / `ALTER TABLE` 等幂等写法

**禁止行为：**
- 禁止修改已执行过的 V1、V2 等历史脚本
- 禁止手动在数据库执行 DDL 而不留脚本记录
