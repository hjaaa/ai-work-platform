6# 风险识别规则

> Agent 在需求分析和方案设计阶段应自动检查以下风险项，命中时主动提醒用户。

## 高风险关键词

| 关键词 | 风险类型 | 自动提醒内容 |
|--------|----------|-------------|
| 金额, 余额, 扣款, 支付, 退款 | 资金安全 | 提醒：涉及资金操作，需确认幂等策略、BigDecimal 精度、对账方案 |
| 删除, 清理, 迁移, 下线 | 数据安全 | 提醒：涉及数据变更，需确认备份策略、回滚方案、兼容性 |
| 密码, token, 鉴权, 权限 | 安全合规 | 提醒：涉及安全变更，需确认角色/权限点、资源范围、脱敏处理 |
| 接口变更, 字段删除, 重命名 | 兼容性 | 提醒：涉及对外契约变更，需确认兼容策略和迁移方案 |
| 大表, 全表, 批量更新 | 性能 | 提醒：涉及大数据量操作，需确认分页方案、索引、执行计划 |
| 定时任务, 调度, cron | 幂等/并发 | 提醒：定时任务需确认幂等设计、分布式锁、失败重试策略 |

## 使用方式

Agent 在解析用户需求描述时，应扫描上述关键词。命中时在需求文档或方案中自动插入对应的提醒项，并要求用户确认处理策略。
