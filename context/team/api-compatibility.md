# API 与数据兼容性规范

## REST API 变更规则

| 操作 | 允许 | 禁止 |
|------|------|------|
| 新增字段 | 可选（nullable / 有默认值） | 必填新增字段 |
| 删除字段 | 先标记 @Deprecated，下个版本删 | 直接删除已发布字段 |
| 重命名字段 | 新增 + 旧字段标记废弃 | 直接改名 |
| 改变语义 | 版本化（`/v2/xxx` 或 Header） | 同字段偷换语义 |

## 数据库 Schema 变更规则

- 新增列：必须有默认值或允许 NULL
- 删除列：先标记废弃 → 下个版本再删
- 修改列类型：禁止导致数据截断

## MQ 消息体变更规则

- 消费者必须能容忍未知字段（不报错）
- 生产者新增字段不影响旧消费者
- 遵循与 REST API 相同的兼容规则
