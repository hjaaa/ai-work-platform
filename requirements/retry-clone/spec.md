# 失败项目手动重试 Git Clone

## 背景

项目创建时会异步拉取 Git 仓库代码，但网络波动可能导致 clone 失败。当前失败后只能删除项目重新创建，体验差。

## 需求描述

在 `/projects` 页面的项目卡片中，为 clone 失败（status=failed）的项目增加"重试拉取"入口：

1. **UI 交互**：鼠标 hover 到失败项目卡片时，显示一个刷新箭头图标按钮
2. **仅失败项目可见**：只有 `status === 'failed'` 的项目卡片才显示此按钮
3. **点击行为**：调用后端 retry API，清理残留代码目录，重新异步 clone
4. **状态流转**：failed → creating → active/failed，复用已有的 WebSocket 进度推送

## 验收标准

- [ ] 失败项目 hover 时显示刷新按钮，正常项目不显示
- [ ] 点击刷新按钮后，卡片状态变为"代码拉取中..."
- [ ] clone 成功后卡片恢复正常显示
- [ ] clone 再次失败时正确显示错误信息
- [ ] 非 failed 状态的项目调用 retry API 返回业务异常
